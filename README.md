# Retail-Sales-Analysis-Excel
## Project Overview

This project focuses on analyzing retail sales data using Microsoft Excel to identify business trends, sales performance and profitability.

## Tools Used
• Microsoft Excel

• PivotTables
• Pivot Charts
• Slicers
• Excel Formulas
• Interactive Dashboard

## Project Objectives

• Analyze overall sales and profit.
• Identify top-performing products.
• Compare regional sales performance.
• Analyze monthly sales trends.
• Evaluate sales channels and product categories.

## Key Performance Indicators (KPIs)

• Total Sales
• Total Profit
• Total Orders
• Average Order Value
• Profit Margin

## Dashboard Features

• Monthly Sales Trend
• Category-wise Sales
• Region-wise Sales
• Top 5 Products
• Sales Channel-wise Sales
• Interactive Slicers

## Project Files

• Retail_Sales_Analysis_Dataset.xlsx – Excel workbook containing the dataset, analysis and dashboard.
